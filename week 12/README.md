# Week 12 성적 데이터 정제 및 분석

## 데이터
- **출처:** 12주차 수업에서 제공한 성적 데이터 (`scores_2026.csv`, `scores_2026_cp949.csv`, `mini.csv`)
- **행 수:** 원본 114행 → 정제 후 100행
- **열 설명:**
  - `학번`: 학생 고유 번호
  - `이름`: 학생 이름
  - `반`: 소속 반 (`1반`, `2반`)
  - `과목`: 시험 과목 (`수학`, `영어`, `프로그래밍`)
  - `점수`: 과목별 시험 점수

## 빈 칸 처리 방법과 이유
- **처리 방법:** `점수` 열이 비어 있는 행 6개를 `dropna(subset=["점수"])`로 삭제했습니다.
- **이유:** 점수가 없는 행을 0점으로 채우면 실제보다 평균이 낮아지고, 그대로 두면 계산이 정확하지 않아서 제거하고 남은 데이터로 평균을 구했습니다. (추가로 중복 행 4개와 0~100 범위 밖 점수 4개도 함께 제거했습니다.)
